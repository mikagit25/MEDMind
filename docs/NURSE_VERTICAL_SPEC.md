## Фаза N2 — Новые типы вопросов (NCLEX-стиль) — ДВИЖКОВАЯ ФАЗА

**Это самая важная техническая часть: обычный MCQ не покрывает сестринские экзамены.**

- **N2.1 Схема вопросов**: расширить модель вопроса полем `question_type` (миграция):
  - `mcq` — существующий (один верный);
  - `sata` — Select All That Apply: несколько верных, оценка all-or-nothing ИЛИ частичная (флаг в вопросе, default all-or-nothing как в NCLEX);
  - `ordered` — расставить действия в правильном порядке (приоритизация): варианты + правильная последовательность; оценка — полное совпадение;
  - `calculation` — числовой ответ (расчёт дозы/скорости): поле точного ответа + допуск (напр. ±0.01), единица измерения отдельным полем, пользователь вводит число.
- **N2.2 Backend**: валидация и скоринг всех 4 типов в квиз-движке и экзамен-режиме; SATA и ordered в exam mode работают с таймером как обычные.
- **N2.3 Frontend + mobile**: UI для каждого типа — чекбоксы (sata), drag-and-drop или нумерация (ordered; на mobile — тап по порядку), числовой инпут с единицей (calculation). Существующие mcq не ломаются.
- **N2.4 AI-генерация**: расширить промпт генерации вопросов поддержкой типов; для nurse-контента генератор обязан выдавать смесь типов (примерно 50% mcq / 25% sata / 15% ordered / 10% calculation).
- **N2.5 Тесты**: скоринг каждого типа (включая частичный балл sata при включённом флаге, допуск calculation, неверный порядок ordered), обратная совместимость старых квизов.

**Приёмка:** квиз со всеми 4 типами проходится на web и mobile; экзамен-режим их поддерживает; старые квизы работают без изменений.

## Фаза N3 — Тренажёр расчёта доз

**Убийственная фича для аудитории: расчёты — ежедневная боль медсестёр и главный страх на экзаменах.**

- **N3.1 Генератор задач** `backend/app/services/dose_calc_generator.py`: параметрические шаблоны задач (НЕ AI-генерация — точность критична, только формулы):
  - доза по массе тела (mg/kg → mg, мл раствора);
  - скорость инфузии (мл/ч из объёма и времени; капли/мин с drop factor);
  - разведение (нужная концентрация из имеющейся);
  - пересчёт единиц (мкг↔мг, мл↔л);
  - детские дозы по массе.
  Каждый шаблон: диапазоны случайных параметров с клинически реалистичными значениями, формула правильного ответа, пошаговое решение (генерируется из тех же параметров — показывается после ответа).
- **N3.2 Режим тренажёра** `/practice/dose-calc` (внутри point-of-care раздела): выбор темы → серия задач с нарастающей сложностью → статистика точности; результаты идут в XP и аналитические события.
- **N3.3 SM-2 связка**: типы задач, где пользователь ошибается, попадают в очередь повторения чаще (использовать существующий механизм из V5 Фазы 5).
- **N3.4 Тесты**: КАЖДЫЙ шаблон покрыт тестом с фиксированными параметрами и проверкой ответа вручную посчитанным значением; property-тест: сгенерированный ответ всегда совпадает с формулой.

**Приёмка:** 5 категорий задач работают; пошаговое решение корректно для любых параметров (выборочная ручная проверка 3 задач каждой категории — в PR); тесты формул зелёные.
