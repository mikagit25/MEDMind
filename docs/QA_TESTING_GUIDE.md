## Известные ограничения (не баги)

- **YouTube видео**: токены Google истекли — загрузка видео недоступна до reauth.
- **Gulf exam AI gen**: вопросы используются из NCLEX-банка, новые не генерируются.
- **Mobile offline**: функция работает только с данными, которые уже закешированы через WatermelonDB.
- **Voice (STT)**: Expo Speech Recognition работает только на реальных устройствах (не в симуляторе).
