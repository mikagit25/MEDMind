## Сценарии для проверки

### 1. Найди раздел
- Зайди на https://medmind.pro
- В меню найди ссылку на Gulf Exams (или через раздел Nurses)
- Убедись что открывается страница со всеми 7 экзаменами выше

### 2. Practice режим (40 вопросов, 60 мин)
- Выбери любой экзамен → кнопка **Practice**
- Ответь на 10–15 вопросов
- **Что проверить:**
  - Таймер идёт и отображается корректно
  - После ответа — подсвечивается правильный вариант
  - Появляется блок с объяснением
  - Если интерфейс на арабском/испанском — появляется кнопка перевода объяснения?
  - Кнопка закладки ★ работает (вопрос помечается)
  - Навигация между вопросами (← →) работает
- Заверши тест досрочно → проверь экран результатов

### 3. Full Simulation
- Выбери **SNLE Full Simulation** (200 вопросов) или **DHA Full** (100 вопросов)
- Пройди 5–10 вопросов
- Объяснения **не показываются** во время симуляции — это правильно
- Заверши досрочно
- **Что проверить в результатах:**
  - Процент правильных ответов
  - Статус «Passed» / «Failed» (порог 65%)
  - Разбивка по категориям (Med-Surg, Pharmacology, Pediatrics…)

### 4. Разбор ошибок после теста
- Вкладка **Wrong** — только вопросы с неправильным ответом
- Вкладка **Bookmarked** — вопросы со звёздочкой
- Вкладка **All** — все вопросы с ответами
- Нажми на любой вопрос — раскрывается подробное объяснение?
- Проверь переключатель языка объяснения (EN / родной язык)

### 4а. Источники (Sources) под объяснением
После ответа на вопрос внизу блока объяснения должен появиться раздел **Sources** с ссылками-источниками:
- 🔬 **PubMed** — реальная научная статья с PubMed (ссылка открывается в новой вкладке на pubmed.ncbi.nlm.nih.gov)
- 📚 **Учебник** — категориальный учебник (например Pharmacology → Karch's; Med-Surg → Ignatavicius)
- 📋 **Регуляторный источник** — для SNLE это SCFHS, для DHA — Dubai Health Authority и т.д.
- **Что проверить:**
  - Ссылки кликабельны и открывают реальные страницы (не 404)
  - Заголовок PubMed-статьи соответствует теме вопроса (хотя бы примерно)
  - Регуляторный источник соответствует выбранному экзамену (не должен быть NCSBN для Gulf)
  - Если источники ещё не подгрузились для конкретного вопроса — раздел просто не отображается (это норма, не баг)

### 5. Readiness Score
- На главной Gulf-странице → вкладка **Readiness Score**
- Если прошёл меньше 30 вопросов — должно быть сообщение «ответь ещё X вопросов»
- После 30+ вопросов — показывает процент готовности и слабые темы
- Переключи экзамен (например SNLE → DHA) — счёт обновляется?

### 6. История сессий
- Вкладка **History**
- Видны предыдущие сессии: дата, экзамен, режим, балл?
- Клик по сессии — открывается разбор?

## Что сейчас в процессе (не баг, так и должно быть)

| Что видишь | Почему |
|---|---|
| У части вопросов только текст объяснения без разбора каждого варианта | Детальные rationales генерируются автоматически, ~16% готово |
| Кнопка «اقرأ بالعربية» или «Leer en Español» показывает «coming soon» | Переводы идут в фоновом режиме |
| Вопросы похожи на NCLEX | Пока используется адаптированная NCLEX-база, Gulf-специфичные вопросы добавляются |
| Раздел Sources отсутствует под некоторыми объяснениями | PubMed-источники добавляются автоматически каждый час, ~30 вопросов за цикл |

## Как фиксировать баги

По каждой проблеме укажи:

1. **Шаги** — что делал, чтобы воспроизвести
2. **Ожидал** — что должно было произойти
3. **Получил** — что произошло (текст ошибки или скриншот)
4. **Устройство / браузер** — Chrome/Safari, телефон/ноутбук
